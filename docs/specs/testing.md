## How it works

- Runtime behavior is implemented in `run-tests.sh` and the test/probe files listed below.
- `qml-static-check.sh` requires `python3` and `rg`, sorts discovered QML and JavaScript paths, copies sources under a temporary `qs/` tree preserving repository-relative paths, and generates `qmldir` files for QML directories and ancestors. JavaScript copies resolve adjacent and parent-directory helper imports without adding module declarations. Singleton declarations follow `pragma Singleton`; ordinary checks and exclusion rechecks lint copied QML via `qmllint -I`. The five fixture-aware cases additionally depend on their Python staging scripts and `Tests/qml_fixture_lint.py`; staged modules are temporary and cleaned on exit. Each invocation rebuilds the tree from current sources and removes it on exit.
